# Reference Images

These images are style references for Lumina image generation.

They define the preferred balance between:

- editorial illustrated humans with subtle naturalistic depth
- clearly illustrated academic environments
- matte, simplified objects and interfaces
- calm ETH-aligned colour use
- neutral to slightly cool daylight
- generous whitespace and readable composition

Use these images as style calibration, not as identity templates.

Do not copy:

- the same faces
- the same hairstyles
- the same clothing combinations
- the same poses
- the same exact scene layouts

When generating new Lumina images, create new people and settings while preserving the visual language.

## Human Rendering

People should feel tangible, individual and human, but not photographic.

Use:

- authentic proportions
- believable gestures
- smooth skin shading without photographic pores
- simplified hair masses with restrained detail
- clean clothing folds with reduced fabric microtexture
- natural expressions without exaggerated posing

Avoid:

- fully photorealistic people
- photographic portraits
- photo skin pores
- hyperrealistic hair
- flat SaaS characters
- repeated identical faces across images

## Environment And Objects

Architecture, furniture, laptops, phones, tablets, bottles, books, notebooks and interfaces should remain clearly illustrated.

Use:

- matte surfaces
- simplified geometry
- crisp silhouettes
- soft natural shadows
- restrained detail
- minimal reflections

Avoid:

- glossy product-photo laptops
- realistic water bottles
- photorealistic furniture
- stock-photo office scenes
- dense dashboard screenshots
- readable generated text
- logos or fake branding

## Colour Direction

Use the Lumina colour system:

- ETH Blue `#215CAF` as the primary visual signal
- ETH Petrol `#007894` for semantic, technical or interface accents
- ETH Grey `#6F6F6F` for secondary structures
- white and very light neutral grey as the main background basis

Keep the colour temperature neutral to slightly cool.

Avoid yellow, beige, cream, sepia or golden colour casts.

## Prompt Reminder

When using these images as references, include a sentence like:

```text
Use the attached reference images only as style calibration for the Lumina illustration language. Do not copy faces, hairstyles, clothing combinations, poses or exact scene layouts. Create new people and a new scene while preserving the reference style.
```
